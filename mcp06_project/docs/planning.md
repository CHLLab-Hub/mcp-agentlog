# MeetMind

## 1.1 배경
AI 회의 어시스턴트를 제작
- Frontend
- Backend
- ASR(음성을 텍스트로 받아쓰기하는 agent)

## 1.2 목표
- Gradio로 회의 생성 ~ 분석 UX를 제작
- 오프라인 모델 ASR/화자분리 파이프라인 제작
- LangGraph 노드 그래프를 사용
- MCP LLM 클라이언트가 회의 Tool을 호출
- 저장된 회의록을 근거로 답하는 챗봇을 제작

## 1.3 시나리오
- 회의 생성 > 샘플 회의록 저장 > LangGraph 분석 > MCP
- 마이크/오디오 업로드 > ASR > 회의록 저장 > 분석
- 질문 > 챗봇 > 저장된 회의를 대상으로 관련 발화와 회의 제목을 답변으로 확인
